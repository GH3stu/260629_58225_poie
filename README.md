# poie（ポイント最適化アプリ）

## サイト概要
poie は、ユーザーの属性（年齢・職業・生活スタイル）に応じて、最適なポイントの貯め方・使い方を提案する  
「ポイント最適化支援アプリ」です。  

### サイトテーマ
- テーマ　ポイントで家を買う
- 目標　ポイントでお家購入の資金の頭金をポイントで賄う（ポイントで家買う＝＞ぽいえ）

### テーマを選んだ理由
ポイントを管理するサイトは複数あり、情報発信は多数見受けられます。  
しかし、個人の属性に合わせた貯め方を支援するサービスは見当たりません。  
そこで当アプリは、ポイ活を始めるユーザー属性に応じた「最適なポイント戦略」を提示します。  

#### ▼ 主な戦略
- 時間を味方につけて、生活の様々な活動でポイントを無理なく効率的に獲得できる方法
- キャンペーン・ブログなど深い情報にアクセス
- 各ユーザーのレビューを通じて、「どのポイントが自分に合うか」を見つける場となる
​
### ターゲットユーザ
- 各ポイントの特徴がわからない人
- 自身が貯めるべきポイントがわからない人
- ポイント連携サービスや連携先がわからない人
- ポイントキャンペーンを知りたい 人
- ポイ活に成功した人 （レビューを投稿する側）

### 主な利用シーン
- 買い物する時
- 何か契約する時
- スマホを持って移動する時
- 暇な時
