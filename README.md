# poie

## サイト概要
### サイトテーマ
poie は、ユーザーの属性（年齢・職業・生活スタイル）に応じて、最適なポイントの貯め方・使い方を情報提供する  
または、ユーザーが自由に訪問・投稿できるレビューサイトです。

### テーマを選んだ理由
ポイントを管理するサイトは複数あり、情報発信は多数見受けられますが、個人の属性に合わせた貯め方を支援するサービスは見当たりません。  
そこで当アプリは、年間約数十万相当のポイント獲得をしている自身の経験を活かし、ポイ活を始めるユーザー属性に応じた「最適なポイント戦略」を提示します。  
時間を味方につけて、生活の様々な活動でポイントを無理なく効率的に獲得できる方法や、キャンペーン・ブログなどへアクセスし情報を集め、各ユーザーのレビューを通じて、「どのポイント戦略が自分に合うか」を見つける場にしたいです。  
目標はポイントで家を買うことができるくらいの資産とすることです。
​
### ターゲットユーザ
- 各ポイントの特徴がわからない人
- 自身が貯めるべきポイントがわからない人
- ポイント連携サービスや連携先がわからない人
- ポイントキャンペーンを知りたい 人
- ポイ活に成功した人 （レビューを投稿する側）

### 主な利用シーン
- 買い物する時
- 何か契約する時
- スマホを持って移動する時
- 暇な時
